# Техническая спецификация AtomPhys

## 1. Математические модели

### 1.1. Классическая Молекулярная Динамика (MD)
Для описания движения атомов используется второй закон Ньютона:
$$ F_i = m_i a_i $$
где сила $F_i$ определяется как градиент потенциальной энергии $U$:
$$ F_i = -\nabla_i U(r_1, ..., r_N) $$

#### Потенциальная энергия (Force Field)
Полная энергия системы:
$$ U_{total} = U_{bond} + U_{angle} + U_{dihedral} + U_{vdw} + U_{coulomb} $$

1.  **Связи (Bond Stretching):** Гармонический потенциал
    $$ U_{bond} = \sum k_b (r - r_0)^2 $$
2.  **Углы (Angle Bending):**
    $$ U_{angle} = \sum k_\theta (\theta - \theta_0)^2 $$
3.  **Ван-дер-Ваальс (Lennard-Jones):**
    $$ U_{LJ} = 4\epsilon \left[ \left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6 \right] $$
4.  **Электростатика (Coulomb):** Метод Ewald Summation или PME (Particle Mesh Ewald) для периодических граничных условий.
    $$ U_{Coulomb} = \frac{1}{4\pi\epsilon_0} \frac{q_i q_j}{r_{ij}} $$

### 1.2. Квантовая коррекция (QM/MM)
Для активных зон используется метод QM/MM (Quantum Mechanics / Molecular Mechanics).
Система разделяется на:
*   **QM-регион:** Активный центр реакции (решается уравнением Шредингера/DFT).
*   **MM-регион:** Окружение (решается классической MD).

Гамильтониан системы:
$$ H_{total} = H_{QM} + H_{MM} + H_{QM/MM} $$

## 2. Алгоритмы

### 2.1. Интегрирование (Velocity Verlet)
Обеспечивает сохранение энергии (симплектический интегратор).
1.  $r(t+\Delta t) = r(t) + v(t)\Delta t + 0.5 a(t) \Delta t^2$
2.  $v(t+0.5\Delta t) = v(t) + 0.5 a(t) \Delta t$
3.  Вычисление сил $F(t+\Delta t)$ и ускорений $a(t+\Delta t)$
4.  $v(t+\Delta t) = v(t+0.5\Delta t) + 0.5 a(t+\Delta t) \Delta t$

### 2.2. Оптимизация соседей (Cell Lists)
Пространство разбивается на ячейки размером $r_{cut}$.
Сложность поиска соседей снижается с $O(N^2)$ до $O(N)$.

## 3. Требования к производительности

| Параметр | Целевое значение | Примечание |
| :--- | :--- | :--- |
| Количество атомов | 1 000 000+ | Для симуляции нано-механизмов |
| Временной шаг (dt) | 0.5 - 1.0 фемтосекунд | Для стабильности связей C-H |
| Производительность | 100 нс/день | На кластере из 8x H100 GPU |
| Точность энергии | < 10^-4 | Относительная ошибка сохранения энергии |
