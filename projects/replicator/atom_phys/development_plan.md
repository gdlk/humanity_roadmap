# План разработки AtomPhys

**Цель:** Создание MVP физического движка за 18 месяцев.

---

## Фаза 1: Ядро (Months 1-6)
*Реализация базовой молекулярной динамики.*

### Спринт 1-2: Инфраструктура
*   Настройка CI/CD (сборка C++23, тесты).
*   Реализация структур данных для хранения атомов (SoA - Structure of Arrays).
*   Базовый интегратор Velocity Verlet.

### Спринт 3-4: Силовые поля (Классика)
*   Реализация потенциала Леннарда-Джонса.
*   Реализация гармонических связей.
*   Валидация на системе "Аргон" (сравнение с LAMMPS).

### Спринт 5-6: Оптимизация
*   Внедрение Cell Lists для поиска соседей.
*   Параллелизация на OpenMP.
*   **Milestone 1:** Симуляция 10,000 атомов аргона в реальном времени (60 FPS) на CPU.

---

## Фаза 2: GPU и Электростатика (Months 7-12)
*Масштабирование и дальнодействующие силы.*

### Спринт 7-8: CUDA Backend
*   Портирование расчета сил на GPU.
*   Оптимизация передачи данных Host-Device.

### Спринт 9-10: Электростатика
*   Реализация PME (Particle Mesh Ewald).
*   Интеграция библиотеки FFTW.

### Спринт 11-12: Python API
*   Создание биндингов (pybind11).
*   Интеграция с Jupyter Notebook для визуализации.
*   **Milestone 2:** Симуляция белка в воде (100,000 атомов) на GPU.

---

## Фаза 3: Квантовые эффекты (Months 13-18)
*Гибридная модель QM/MM.*

### Спринт 13-14: Интерфейс QM
*   Разработка API для подключения внешних QM-солверов.
*   Реализация схемы разделения сил (Force Mixing).

### Спринт 15-16: DFT-Lite
*   Реализация упрощенного DFT-метода (Tight Binding) для углеродных нанотрубок.
*   Тестирование на разрыве C-C связи.

### Спринт 17-18: Релиз 1.0
*   Документация и примеры.
*   Бенчмаркинг.
*   **Milestone 3:** Симуляция сборки простой молекулы (бензол) манипулятором.
